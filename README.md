<h3>Bot-Control</h3>
<img src="botcontrol.jpg" alt="bot-control" style="width:300px;">
<p>
    This code, written in Python, uses a bot to control a Windows device via a Telegram bot.
</p>
<h4>Installation</h4>
<p>To install Bot-Control, follow these steps:</p>
<ol>
    <li>Open your terminal.</li>
    <li>Run the following command to clone the Bot-Control repository:
        <pre><code>https://github.com/HexRoot-x/Bot-Control.git</code></pre>
    </li>
    <li>Navigate to the Bot-Control directory:
        <pre><code>cd Bot-Control</code></pre>
    </li>
    <li>Install the required dependencies:
        <pre><code>pip install -r requirements.txt</code></pre>
    </li>
    <li>Run the Bot-Control tool:
        <pre><code>python Bot.py</code></pre>
    </li>
</ol>
<h4>Usage</h4>
<p>
    First, change the token and ID in the main file for it to function.
</p>
<pre><code>Next, run the Bot.py file until it starts, then enter the bot by running /start. The commands will appear and control will begin.</code></pre>
